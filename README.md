# Planilhador de Equipamentos — Releases

Este repositório é o **canal público de atualizações** do Planilhador de Equipamentos.

Ele não contém o código-fonte do programa. As Releases publicadas aqui contêm somente os pacotes necessários para instalação e atualização, acompanhados de seus arquivos SHA-256.

## Arquivos esperados por versão

- `Planilhador_Equipamentos_EXE_vX.Y.Z.zip`
- `Planilhador_Equipamentos_EXE_vX.Y.Z.zip.sha256`
- `Planilhador_Equipamentos_Update_vX.Y.Z.zip`
- `Planilhador_Equipamentos_Update_vX.Y.Z.zip.sha256`

O desenvolvimento e o código-fonte permanecem em repositório privado.
